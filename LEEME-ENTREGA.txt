EJECUTAR LOCALMENTE
1. Instala Node.js y npm si no los tienes.
2. Abre una terminal en esta carpeta y ejecuta: npm ci
3. Copia .env.example a .env y configura la URL y clave pública anon de tu proyecto Supabase.
4. Ejecuta: npm run dev
5. Abre la dirección que indique Vite.

VALIDAR Y COMPILAR
npm run typecheck
npm run build

SUBIR A GITHUB
Copia el contenido de esta carpeta dentro de tu clon del repositorio existente.
Incluye las carpetas ocultas .openai y los archivos .gitignore y .env.example.
Revisa git diff, crea un commit y haz push desde ese clon.
Este ZIP es una instantánea del código; no contiene el historial .git.
No subas .env, node_modules ni dist.
